# ▶️ How to Run

## Requirements

- Python 3 installed on your computer

## Installation

1. Clone this repository:

```bash
git clone YOUR_REPOSITORY_LINK
```

2. Open the project folder:

```bash
cd python-string-indexing-practice
```

3. Run the program:

```bash
python main.py
```
